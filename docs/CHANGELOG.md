# KumustaHub CHANGELOG

人間が読める変更履歴。Git履歴を補完する。

## 2026-05-30

### Added

- 公開主要導線向けのローカルUI辞書を追加し、トップ、検索、ナビゲーション、店舗カードを日本語/英語表示に対応した。
- ヘッダーに日本語/英語の表示切替を追加し、`?lang=ja|en` とcookieで表示言語を保持するようにした。

### Changed

- 一覧、検索、トップ、お気に入りで使う店舗取得を軽量化し、カード表示に不要な口コミと複数写真の取得を避けるようにした。
- 店舗詳細の公開店舗取得をrequest cacheで共有し、metadataと本文の重複DB取得を減らした。

## 2026-05-26

### Added

- 地図UIはLeafletで実装し、OSM標準タイル利用時はtile usage policyを守る方針に決定した。
- 検索結果と店舗詳細にLeaflet/OpenStreetMapベースのアプリ内地図を追加した。
- モバイル検索結果で一覧表示と地図表示を切り替えられるようにした。

## 2026-05-23

### Added

- admin の通報一覧と口コミ一覧で、通報件数が多いレビューを優先確認できるようにした。
- 口コミ写真と店舗写真アップロードで、送信前に画像形式、枚数、サイズ制限を確認できるようにした。
- 口コミの非表示/再表示操作に、未解決通報のステータス更新を連動させた。
- MVPでの口コミ削除方針を、公開面では非表示を削除相当として扱う方針に決定した。
- 初期口コミを運営が捏造しない方針を明文化した。
- 初期公開店舗の重点都道府県別最低件数と正式リリース目標件数を決定した。
- 多言語対応の初期方式を、既存URL維持、cookie/query切替、ローカルTypeScript辞書管理に決定した。
- 多言語対応で口コミ本文をUI翻訳対象外とし、原文保持する方針を明文化した。
- MVPでの運営者情報の公開範囲を、KumustaHub operations team と問い合わせフォームに集約する方針に決定した。
- 本番公開画像をSupabase Storage管理へ寄せ、外部URL直書きを段階撤廃する方針に決定した。
- 画像アップロード前にブラウザ側で1200px程度へ縮小する方針に決定した。
- 画像アップロード時にブラウザ側で長辺1200px程度へ縮小し、WebP優先で送信する処理を追加した。
- 既存画像URLの棚卸しとStorage移行チェックリストを追加した。
- Storage容量とegressの監視手順、警戒ライン、初動対応を追加した。
- 運用手順として管理者追加/削除、Supabase usage / DB metrics確認、容量警戒ラインを追加した。
- 実装済み機能に合わせて正式リリース判定チェックリストと次タスクの優先順を更新した。
- GitHub Actions で lint、typecheck、build を実行するCIを追加した。
- 性能改善の原因候補と後続タスクを記録した。

- admin画面に問い合わせ一覧とstatus更新を追加。
- 利用規約とプライバシーポリシーを正式リリース前提の文面へ更新。
- admin画面でブランド、カテゴリ、エリアを追加/編集/削除できるようにした。
