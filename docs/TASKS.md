## 次に着手すべきタスク

現在の進捗から見ると、次は **店舗追加申請フロー** が最優先。

理由:

- `/store-request` は画面のみで、送信してもDB保存されない
- ユーザー参加型の店舗DB拡充に直結する
- adminのAdd Storeは既にあるため、申請承認フローにつなげやすい
- 正式リリース判定に「店舗追加申請」が残っている

推奨実装順:

1. 店舗追加申請テーブルを追加
2. `/store-request` のフォームをserver action化
3. 申請内容をDB保存
4. admin画面に申請一覧を表示
5. adminで承認/却下
6. 承認時に `stores` へ反映
